# マンガ更新ナビ

公式Web漫画サイトの更新（無料公開・先読み）を1ページにまとめるサイトです。
GitHub Actions が1日3回（日本時間 0:05 / 12:05 / 18:05）自動で情報を集め、GitHub Pages に公開します。

## 対応サイト

| サイト | 取得方法 | 無料/有料の判定 |
|---|---|---|
| 少年ジャンプ＋ | 公式RSS | RSSの無料期間情報 |
| コミックガルド | 公式RSS＋トップページ | RSS＝先読み（有料）、トップページ曜日別欄＝無料 |
| コミックアース・スター | 公式RSS | RSSの無料期間情報 |
| コミックDAYS | 公式RSS | RSSの無料期間情報 |

## ファイル構成

- `scripts/build.py` … 情報を集めてページを作るプログラム
- `templates/index.html` … ページの見た目
- `tests/` … 実サイトにアクセスしない動作確認
- `.github/workflows/update.yml` … 自動実行の設定

## 取得できなくなったときの通知（任意）

Discord の Webhook URL を、リポジトリの Settings → Secrets and variables → Actions に
`DISCORD_WEBHOOK_URL` という名前で登録すると、取得0件・エラー・7日以上新着なしのときに通知が届きます。

## 注意

- 各サイトへのアクセスは1回の実行につき5回（1日15回）だけです。
- 60日間リポジトリに変更がないと、GitHub が自動実行を止めることがあります。その場合は Actions 画面から再開してください。
